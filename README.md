# NarrativeOS

NarrativeOS is an evidence-gated video-production workflow for Hermes. It provides durable stage control, research and continuity artifacts, claim-to-shot evidence links, semantic asset-matching contracts, timeline IR, FFmpeg rendering, audio/caption pipelines, QA, and optional provider adapters.

The canonical repository is [Hxtra/NarrativeOS](https://github.com/Hxtra/NarrativeOS).

The project intentionally blocks external research, vision, TTS, generation, and publishing stages until configured adapters produce real evidence and provenance.
